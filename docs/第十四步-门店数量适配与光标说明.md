# 门店数量适配与光标说明

概览标题改为“门店经营，一眼看清。”导航、面包屑、加载提示和源码中的接口范围说明不再绑定六家门店。当前学习配置仍有六家，不需要为了文案删除门店。

学习重点是数据驱动：`loadOverview` 的卡片根据 `report.stores` 遍历，完整性提示也必须以 `report.stores.length` 为分母。原先卡片数量是动态的，“有销售数据/有推广账本”的分母却写死为 6，本次已修复。

门店配置入口是 `data/stores.json`。`StoreHub` 根据配置逐店读取业务文件和推广账本，不限制为六家。增加门店需要一并提供该店数据和推广账本；本次没有新增网页里的门店创建、账号权限或外部平台自动接入。

验证：`node artifacts/check_store_overview.cjs` 通过一店、三店部分缺数据及空列表渲染检查；空销售数据展示“—”，没有补零。`node --check ecommerce_agent/web_assets/app.js` 通过。

## 普通文字旁闪动的竖线

指标由普通文字节点渲染，源码没有开启 `contenteditable` 或 `document.designMode`。浏览器的“光标浏览”（通常用 F7 切换）也会在不可编辑的网页文字上显示闪动光标，用于键盘定位、选择文字；它不代表指标能被改写。

本次浏览器内部设置页受工具安全策略限制，未能直接读取该开关，因此“光标浏览已开启”仍是根据截图的判断。请在 Edge 设置中搜索“光标浏览”，关闭“使用文本光标导航页面”，或按 F7 检查切换。输入框内正常光标应该保留，没有用禁用文本选择或隐藏所有光标来掩盖问题。
