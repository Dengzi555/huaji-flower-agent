# 门店差异与小时推广曲线

界面收敛为门店经营概览、经营调查、推广分析，移除门店设置、异常跟进及所有建跟进入口。旧数据库和报告没有删除，历史兼容接口暂保留；它们不再是当前界面流程。

推广分析底部大段说明改成折叠的数据说明，导出的 JSON 继续记录来源与口径，学习数据没有被伪装成平台真实记录。

## 先有业务差异，再有指标差异

`store_workspace.py` 的 `PROFILES` 为各门店分别定义规模、访客与转化关系、费用率、营业时间和停投时间。经营好的门店不必是推广最贵的门店；高费用也不保证高成交。

按用户描述组织学习场景，并非宣称行业基准：

| 门店 | 营业与推广 | 10月25日营业额 | 推广费用率 |
|---|---|---:|---:|
| 深圳南山店 | 全天营业、深夜低价持续投放 | 36,790.54 | 9.82% |
| 重庆南岸店 | 8–24点营业、23点后停投 | 15,742.43 | 12.39% |
| 郑州唐人街店 | 9–23点营业、20点后停投 | 3,530.02 | 19.31% |
| 成都玉林路店 | 8–24点营业、22点后停投 | 7,148.68 | 11.16% |
| 成都春熙路店 | 全天营业、深夜低价持续投放 | 47,862.48 | 9.33% |

日期和商品也有独立变化，不再是原来统一乘一个系数。访客、订单、件数仍为整数，金额保留分币。

## 小时账本的关键约束

- 午饭、下午茶、晚饭为主要需求峰段，加入有限波动，不做完全相同的曲线。
- 每小时/模式扣费等于点击数乘该时段 CPC，CPC 为1.10、1.20、1.35、1.50、1.80、2.20或2.60元。
- 夜间营业的大店低价持续投放，小店停投后仍可有自然访客和成交。停投不是停业，零广告费不等于零营业额。
- 日级营业额按整数最大余数法分配到小时，分币合计不变；订单、商品访客汇总也守恒。小时分布为生成场景，不是平台观测事实。
- 未营业时段有明确 `operating=false`，营业额/订单/访客显示“—”，状态显示未营业。它是已知停业，不是采集缺失；真正缺小时的账本仍拒绝加载。
- 访客列是各商品UV的汇总，跨商品没有去重，不称作店铺独立访客。

## 曲线如何画

接口先用分币计算小时数据和费用率，前端用 SVG 将总扣费、手动、自动绘成三条折线，背景标注三段峰期。悬停小时点显示精确金额、点击和费用率；已知未营业的小时不连接成零费用曲线。

前端不根据费用率去反算、编造金额。广告按点击时点、订单按支付时点，不据此认定广告转化归因。

## 验证和回退

127 项测试通过：覆盖跨店隔离、分币扣费、费用率边界、夜投、停投后自然成交、未营业矛盾记录与缺小时拒绝。原输入备份位于 `artifacts/before-business-v11`，历史报告和数据库保持原样。
