# 展示光标与全局详情栏

已移除概览底部的“日级学习快照……”常驻文字、顶部“经营快照·只读调查”标签，以及左侧模块序号。数据与能力说明仍可在调查页展开查看，底层数据来源标识不变。

## 详情栏为什么打不开

原来 `#inspector` 放在 `#investigation-workbench` 内。切换到概览、推广或设置后，调查模块带有 `hidden`，子元素即使移除自己的 `hidden` 也仍然不可见。这是父元素隐藏造成的问题，和接口没有关系。

现在详情栏是 `main` 的直接子元素，以独立固定抽屉显示。顶部按钮在不同模块都能打开、关闭；新增关闭按钮和 Escape 关闭。没有当前调查时显示选择调查的提示，不伪造任务详情。

## 展示文字的光标

只判断为浏览器光标浏览不足以改善当前页面体验，本次增加展示层约束：普通页面文字使用透明插入光标；经营卡片和标题使用普通鼠标指针且不提供文本选区。`input`、`textarea` 和明确可编辑区域恢复正常插入光标。没有修改浏览器设置，报告和证据区域仍可选取文字。
